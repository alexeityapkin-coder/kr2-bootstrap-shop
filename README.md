# Сайт сервисного центра по ремонту ноутбуков
**Автор:** Тяпкин Алексей

## Четыре страницы сайта
1. `index.html` — главная страница с кратким описанием и переходами.
2. `advantages.html` — преимущества сервиса.
3. `prices.html` — таблица примерных цен.
4. `about.html` — информация о сервисном центре.

## Используемые технологии
HTML5, CSS3, Bootstrap 5.3.8.
